도서대여관리 프로그램

  • 도서등록
  • 도서목록조회/수정
  • 대여현황조회
  • 흠으로
    •  국제 대여점의 도서등록, 대여정보 데이터베이스를 구축하고, 도서, DVD 대여관리를 위한 프로그램이다.
    프로그램 작성 순서
    1. 도서정보 테이블을 생성한다
    2. 대여정보 테이블을 생성한다
    3. 도서정보, 대여정보 테이블에 제시된 문제지의 참조데이터를 추가 생성한다.
    4. 도서정보 입력 화면프로그램을 작성한다.
    5. 도서정보 조회 프로그램을 작성한다.
    6. 대여 정보 조회 프로그램을 작성한다.
